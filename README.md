
# ScholarAI

**AI-Powered Scholarship and University Recommendation System**

ScholarAI is a final-year project that recommends universities and scholarships tailored to a student's academic profile, using content-based filtering to match preferences such as CGPA, budget, and program of interest with relevant opportunities.

## Tech Stack

- **Frontend:** React
- **Backend:**Python FastAPI (Modular Monolith)
- **AI Service:**  (Content-Based Filtering Engine)
- **Database:** MySQL

## Features

- Student registration, login, and profile management
- Content-based university and scholarship recommendations
- University and scholarship search and filtering
